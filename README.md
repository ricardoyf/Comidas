# Comidas

Web móvil para consultar el plan semanal de comidas y cenas de forma compacta.

## Estado

Versión: **main actual** (sin versión semántica publicada).

## Funciones

- Muestra la semana completa con día, fecha, comida y cena.
- Conserva un histórico navegable de semanas anteriores.
- Incluye el recetario HTML usado como referencia.
- Está optimizada para consulta rápida desde el móvil.
- Funciona como web estática, sin servidor ni compilación.

Web: <https://ricardoyf.github.io/Comidas/>
